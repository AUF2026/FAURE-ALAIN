This is my personal page, connected to my Medium profile and the existing AUF2026 project.

It is a space where I bring together my personal theses, ideas, reflections, and topics I want to explore. Not a generic blog. Not an institutional presentation. A personal point of view, documented and developed over time.

Questa è la mia pagina personale, collegata al mio profilo Medium e al progetto AUF2026 già esistente.
